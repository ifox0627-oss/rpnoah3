# [드림 퀘스트] 음성 질문 인식(STT) 및 전문가 답변 음성(TTS) 기능 구현 계획

학생들이 키보드 입력뿐만 아니라 마이크를 통해 자연스러운 음성으로 질문하고, 10년 차 직업 전문가 멘토의 생생한 음성 답변을 귀로 들으며 몰입감 넘치는 1:1 진로 면담을 체험할 수 있도록 음성 대화 시스템을 구축합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질의응답을 통해 확정된 3가지 핵심 UX 결정 사항입니다:

- **확정 1 (음성 전송 흐름)**: 음성 인식(STT)된 텍스트가 입력창에 실시간으로 표시되고, 학생이 내용을 눈으로 확인하거나 수정한 뒤 **[보내기] 버튼 또는 Enter 키를 눌러 직접 전송**합니다. (발음 오인식에 따른 엉뚱한 전송을 방지)
- **확정 2 (전문가 답변 출력)**: 전문가의 텍스트 답변이 말풍선에 출력될 때, 브라우저 음성 합성(TTS)을 통해 **다정한 멘토 음성으로 함께 읽어주기**를 제공합니다. 개별 말풍선 음성 다시 듣기 및 음소거/중지 버튼을 함께 지원합니다.
- **확정 3 (녹음 인터랙션 연출)**: 음성 인식 중에는 마이크 버튼에 **네온 펄스 링 애니메이션**과 **실시간 음성 파형(오디오 비주얼라이저 바)**이 활성화되어 시각적인 생동감을 부여합니다.

## 1. Overview & Core Concept

- **목적**: 텍스트 타이핑이 서툴거나 느린 초등학교 저학년 및 청소년 학생들도 막힘없이 질문하고, 눈과 귀로 동시에 직업 멘토와 교감하는 인터랙티브 시뮬레이션 환경 제공.
- **핵심 가치**:
  - **접근성 극대화**: 마이크 버튼 원클릭으로 한국어 자연어 음성을 인식(`ko-KR`).
  - **오발화 방지 안전장치**: 인식된 문장을 입력창에 자동 삽입 후 사용자가 수정할 수 있는 검토 버퍼 제공.
  - **음성 인터랙션 피드백**: 녹음 중 시각적 오디오 파형 바, 인식 완료 비프음, 멘토 답변 자동 낭독.

## 2. User Experience & Visual Design

### 2.1 마이크 녹음 및 음성 입력 흐름 (Student Voice Flow)
1. **마이크 버튼 클릭**: 입력창 우측/좌측의 마이크 아이콘(`Mic`) 버튼 클릭 시 브라우저 마이크 권한 요청 및 음성 수음 시작.
2. **녹음 진행 중 연출**:
   - 마이크 버튼이 레드/로즈 컬러의 펄스 링(`animate-ping`, `animate-pulse`)으로 전환.
   - 입력창 상단에 **"듣고 있어요... 편하게 말씀해 주세요"** 안내 배너와 **5~6개의 춤추는 오디오 파형 바(Waveform bars)**가 실시간 진폭 연출.
   - 실시간 중간 인식 결과(Interim transcript)가 입력창에 즉각적으로 타이핑되듯 표시.
3. **음성 인식 종료**:
   - 학생이 말을 멈추거나 [녹음 완료/정지] 버튼을 누르면 최종 문장 확정.
   - 텍스트 입력창에 포커스가 유지되며, 학생이 원하는 경우 오탈자 수정 가능.
   - 기존의 [보내기] 버튼(`Send`)을 눌러 AI 전문가에게 질문 전달.

### 2.2 전문가 음성 답변 재생 흐름 (Mentor TTS Flow)
1. 전문가의 답변이 도착하면 말풍선 출력과 동시에 멘토의 다정한 한국어 음성(여성/남성 캐릭터 톤)으로 자동 낭독 시작.
2. 말풍선 우측 상단에 미니 스피커 버튼(`Volume2` / `Square`)이 제공되어:
   - 재생 중일 때 부드러운 사운드 웨이브 아이콘 회전.
   - 클릭 시 언제든지 음성 재생을 중지하거나 다시 들을 수 있음.
3. 상단 헤더의 전체 소리 토글 버튼(`isSoundOn`)과 유기적으로 연동되어 음소거 상태일 때는 TTS 자동 재생도 조용히 비활성화.

## 3. Key Product Decisions & Trade-Offs

- **결정 1: Web Speech API (SpeechRecognition & SpeechSynthesis) 채택**
  - *선택 방식*: 브라우저 표준 Web Speech API (`webkitSpeechRecognition`, `window.speechSynthesis`) 활용.
  - *이유*: 오디오 파일을 서버로 스트리밍 전송하고 인코딩하는 별도 복잡성 및 지연 시간(Latency) 없이, 브라우저 로컬 엔진에서 지연 시간 0에 가깝게 한국어 음성을 실시간 변환.
  - *폴백(대체안)*: 만약 지원하지 않는 브라우저이거나 마이크 권한이 차단된 경우, 친절한 툴팁 안내와 함께 일반 텍스트 입력 모드로 자연스럽게 유지.

- **결정 2: 음성 인식 텍스트의 사전 검토 단계 유지**
  - *선택 방식*: 자동 즉시 전송 대신 입력창 삽입 후 확인 전송.
  - *이유*: 초등학생들이 마이크에 "아, 그러니까요 소방관님 불이 날 때..."처럼 주저하거나 잡음이 섞였을 때 수정할 기회를 주어, AI 모델에 더 정제된 질문이 전달되고 미션 키워드 매칭 성공률이 향상됨.

- **결정 3: 직업 멘토별 음성 톤 미세 조정**
  - *선택 방식*: `speechSynthesis`의 `pitch` 및 `rate` 파라미터를 직업 성격에 맞게 매핑 (예: 소방관은 차분하고 힘찬 톤, 파티시에는 부드럽고 밝은 톤).

### 4.1 구현 모듈 계획
1. **`src/utils/speech.ts`**:
   - `SpeechRecognitionService`: Web Speech API 래퍼 (마이크 권한 확인, 연속 음성 인식, 한국어 언어셋 `ko-KR` 지정, 오류 복구).
   - `SpeechSynthesisService`: 브라우저 TTS 래퍼 (한국어 음성 보이스 탐색, 발화 제어, 문장 정제).
2. **`src/components/AudioWaveform.tsx`**:
   - 마이크 활성화 시 펄스 및 오디오 웨이브 막대 애니메이션을 표현하는 인터랙티브 컴포넌트.
3. **`src/App.tsx` 연동**:
   - 입력창 영역에 마이크 토글 버튼(`Mic` / `MicOff`) 및 음성 파형 상태 배너 추가.
   - 음성 인식 완료 시 `inputValue`에 실시간 텍스트 반영.
   - 전문가 답변 수신 시 자동 음성 재생 연동 및 각 말풍선에 '다시 듣기 / 멈추기' 버튼 제공.
